# Personal Portfolio Website

A responsive personal portfolio website created to showcase my skills, projects, learning journey, and professional growth as an aspiring Full Stack Developer. The website serves as a central platform where visitors can learn about me, explore my technical skills, view my projects, and connect with my GitHub profile.

## Features

* Responsive and user-friendly design
* Personal **About Me** section
* Technical skills showcase
* Dedicated projects section
* Learning journey and career development section
* GitHub profile integration
* Clean, modern, and interactive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Highlights

### Personal Portfolio Website

This project is a fully responsive portfolio website designed to present my journey into the technology field and showcase my growth as a developer. The website includes multiple sections that provide a complete overview of my profile, technical knowledge, projects, and continuous learning.

The **About Me** section introduces my background and career journey, while the **Technical Skills** section highlights the programming languages, web technologies, and tools I have worked with. A dedicated **Projects** section allows me to showcase my work with project descriptions and relevant links.

The portfolio also includes a **Learning Journey** section to highlight the technologies and concepts I am currently exploring, including **Python, Django, Full Stack Development, and AI Technologies**. Additionally, the website provides direct access to my **GitHub profile**, making it easy for visitors and recruiters to explore my repositories and development work.

The project focuses on building a clean and professional user interface, ensuring that the website is responsive and accessible across different screen sizes and devices.
